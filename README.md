# Business Chinese Flashcards

A small browser-based app for learning business Chinese vocabulary. Study each word with its Hanzi, pinyin, Thai meaning, and English meaning.

## Features

- Flip flashcards to reveal pinyin and translations; play the Chinese pronunciation.
- Study by lesson, filter by memorization status, shuffle cards, and track progress.
- Search the vocabulary list and add, edit, or delete words.
- Create lessons, copy a lesson's vocabulary, and restore the original 60 words.
- Save vocabulary, lesson names, memorization status, and speech rate in browser storage.

## Requirements

- A modern browser with JavaScript and `localStorage` enabled.
- Internet access to load Tailwind CSS and Google Fonts from their CDNs.
- Browser speech synthesis and a Chinese voice for pronunciation playback.
- Clipboard access in a secure context (HTTPS or localhost) to copy vocabulary.

No installation, sign-in, or backend is required. Open `index.html` in a browser to use the app. Your changes are stored in that browser and are not synced; clearing its site data removes them.
