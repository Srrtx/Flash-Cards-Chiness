# Chinese Flash Cards

Mini-project for learning Chinese vocabulary.

## Requirements

- No user sign-in is required.
- No backend call is required for vocabulary editing.
- Added and edited vocabulary is cached in the browser with `localStorage`.
- Each card contains a Chinese word, pinyin, Thai meaning, and English meaning.
- Users can mark words as memorized or unmemorized.
- Users can create additional lessons from the “เพิ่มคำศัพท์ใหม่” form.

Lesson names and vocabulary changes are stored locally in the current browser. Clearing browser storage removes those local changes.
